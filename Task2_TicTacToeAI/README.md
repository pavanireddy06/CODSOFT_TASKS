# 🎮 AI Tic-Tac-Toe

An AI-powered Tic-Tac-Toe game developed in Python using the Minimax Algorithm as part of the CodSoft Artificial Intelligence Internship.

## Features

- Human vs AI
- Human vs Human
- Unbeatable AI using Minimax
- Scoreboard
- Play Again option
- Clean modular code
- Console-based UI

## Technologies

- Python 3
- Object-Oriented Programming
- Minimax Algorithm
